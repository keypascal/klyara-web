Adding a guide

The Uni lives in one place:

  • This folder — 05_Website\uni\, published at klyara.com/uni. Double-click any guide there and it opens; nothing needs to be running.

To add or change a guide: put the file in this folder, add a card to index.html, then commit and push. It is live in about a minute. There was a second copy in 11_Uni with a sync-to-website.cmd script; it was removed on 27 August 2026 because the script overwrote this folder's index.html.

Self-contained HTML is the format — one file, no build step, opens anywhere, still readable in ten years.

Read this before you put anything in here. Every file in this repository is served publicly — klyara.com/uni/<filename> works for anyone who guesses it. These pages are marked noindex and excluded in robots.txt, so search engines leave them alone, but that is not access control. No passwords, no client data, no identity documents, no bank details. If it would be a problem in a competitor's hands, it does not go in the Uni.
